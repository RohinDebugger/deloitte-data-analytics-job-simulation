## Overview
Simulated real-world data analyst tasks for Deloitte's client, Daikibo Industrials, 
covering two areas: equipment downtime analysis and workplace pay equality investigation.

## Task 1: Telemetry Data Analysis (Tableau)
- Analyzed Daikibo's machine telemetry data to identify equipment downtime patterns
- Built a calculated field to quantify potential downtime (10 mins per "Unhealthy" status)
- Created two visualizations: Down Time per Factory, Down Time per Device Type
- Built an interactive dashboard with cross-filtering — selecting a factory filters 
  the device-type chart to show only that factory's machines
- Identified the factory with the highest total downtime (Daikibo Factory Seiko)

## Task 2: Pay Equality Investigation (Excel)
- Analyzed an equality score dataset (-100 to +100 scale) across factories and job roles
- Classified each role into Fair / Unfair / Highly Discriminative based on defined thresholds
- Supported Deloitte's Forensic Technology team in investigating internal pay-equality complaints
